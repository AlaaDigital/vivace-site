## الربط مع Cloudflare Pages (كما اتفقنا):
1. ادخل dash.cloudflare.com > Workers & Pages > Create application > Pages > Connect to Git
2. اختار repo `vivace-sydney`
3. Framework preset: Vite
4. Build command: `npm run build`
5. Build output directory: `dist`
6. Deploy

Cloudflare باش يعمل build و يطلع الموقع live في دقيقة. كل push جديد على GitHub يعمل deploy تلقائي.
